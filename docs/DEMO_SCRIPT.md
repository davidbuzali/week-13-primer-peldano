# Demo video script - Primer Peldaño Week 13 (3:30)

Record the live site at `https://week-13-primer-peldano.vercel.app`. Use invented content only. Keep the final 30 seconds for what changed your mind.

## 0:00-0:25 - The door opens, but real use stops

**On screen:** Show the live URL, prototype label, and `Sin compromiso, el proceso se detiene aquí`.

**Say:** “Primer Peldaño helps make useful informal work legible for one opening, but it begins with the constraint. There is no real employer commitment, so the product asks for no real evidence. The employer must act before the worker invests time.”

## 0:25-0:55 - Open the fictional task

**On screen:** Click `Abrir demo inventada`. Point to the invented employer, vacancy, four criteria, and privacy boundary.

**Say:** “Everything in this exercise is invented and has no hiring consequence. A visitor practices with bounded fields, and the page blocks sensitive-looking information. Nothing is stored remotely or sent to an employer.”

## 0:55-1:25 - Honest term matching

**On screen:** Map `Pedidos de repostería` and open one provenance disclosure.

**Say:** “Week 13 removes the word ‘supported.’ The system now shows term overlap, possible missing information, or no term overlap. It uses only visible text, cites its source, and repeats that overlap is not verification or sufficiency.”

## 1:25-2:00 - Challenge the green cards

**On screen:** Select `Trampa: lista de palabras` and map it.

**Say:** “This example deliberately repeats all preferred terms without a coherent account of what happened. It turns all four cards green, which exposes the limitation instead of hiding it. The correct interpretation is still ‘insufficient’; a human must clarify, continue, or decline under a published rubric.”

## 2:00-2:40 - Five boundaries and local analytics

**On screen:** Show the five checks, relationship category, optional note, local event count, download, and reset.

**Say:** “The test measures comprehension, not praise. A participant explains five boundaries aloud, records whether they completed the task without help, and identifies the adversarial example. Events are anonymous and local. A saved note appears only in a user-initiated download, and reset clears both storage and the visible form.”

## 2:40-3:00 - Test-fix-redeploy evidence

**On screen:** Keep the reset control visible.

**Say:** “Deployment one revealed that reset cleared storage but left the note visible. I fixed the component lifecycle, reran 20 tests, rebuilt, redeployed, and reproduced the exact path. The note now clears and mobile width has no horizontal overflow.”

## 3:00-3:30 - What changed my mind

**On screen:** Return to the real stop-state.

**Say:** “What changed my mind is that a positive reaction is weak evidence, while one dangerous misunderstanding can invalidate the product. The next proof is not more software: it is five honest outside sessions, including three strangers, followed by one employer accepting a real evidence standard before a worker invests time.”
